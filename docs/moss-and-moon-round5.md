The new release gate is deliberately layered. It preserves both the old and observed-weight temporal comparisons as evidence, rather than treating a temporal increase as proof of newly constructed application storage. Every interval is compared against all four unchanged full-path control observations, before and after subsystem removal. The predictive allowance is `3 * sqrt(s² * (1 + 1/n) + measuredSampleSE²)`, where `s²` is the measured between-control-interval variance and `n = 4`; the multiplier remains three. This accounts for the observed execution-tier/interval variability instead of fitting a fixed byte constant to the old failure. It is an empirical control envelope, not a guarantee about all V8 versions. Exact classified source SHA, explicit storage/closure checks, unknown app stack rejection and independently tracked surviving types supplement the byte envelope. A changed runtime source requires renewed classification. Already-collected types remain a measurement limitation.
