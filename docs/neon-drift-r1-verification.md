# Neon Drift round 1 verification

Build `neon-drift-rebuild-r1`, game version 1.1.0. The source and static runtime were rebuilt together with pinned Three.js 0.170.0 and esbuild 0.25.0. Original models/audio and Three.js notices remain local. Export UUIDs are now seeded for reproducible GLTF assets and manifests.

Run `npm --prefix games/neon-drift run acceptance` from the repository root with port 8105 free. It builds, runs all 60 unit tests, starts the prescribed HTTP server, drives one headless Chrome with SwiftShader, writes evidence, closes Chrome and stops the server. This round used `NEON_ARTIFACT_DIR=/workspace/stteak8/work/neon-drift/rounds/r1`. The resulting `acceptance.json` and `acceptance.log` are retained there.

The suite completed a legal two-lap race in 135.73 seconds and a full 120-second drift challenge through analog controller input. No positions, clocks, checkpoints or scores were assigned by the test. It verified result persistence, exact interrupted-race restoration, blur pause/input release, initial gesture-only audio creation, audible waveform data, suspended-context recovery, 1280×720 / 1920×1080 / mobile dialogs, result focus, and WebGL loss/restoration. Console/page errors: 0; failed requests: 0; CSP violations: 0. Requests are tracked through completion before reload; intentionally navigating during model loading is avoided in the acceptance flow.

A separate keyboard browser check followed the help dialog's W / A+Space / release / brake / R sequence, earned all five tutorial tasks with zero collisions, saved through the new Finish School button and restored the completed status after reload. It checked every district preview, explicit Low/High/Auto drawing-buffer widths and the tutorial HUD without overlapping route/event prompts. See `tutorial.png` and `polish-smoke.log` in the round evidence directory.

Measured frame intervals: average 65.07 ms, p95 133.40 ms, 3884 retained playable frames. Drawing buffer 640×360; final scene 46 draw calls / 15084 triangles. Gaps over two seconds pause and save the game rather than fast-forwarding; those pauses are reported separately in `schedulerGaps`. Frame timing remains below the rubric's polished-performance target on this shared SwiftShader host. No claim of an independent score of 90 is made.

Collected heap at warm-up and after three wall-clock minutes (including scheduler pauses): 8,059,892 → 8,712,928 bytes. DOM listener count: 76 → 76. Profiler/history arrays, browser-event lists, smoke/sound voices and scene resources are bounded. The acceptance suite asserts bounded heap and listener growth; it does not substitute that measurement for all-device performance testing.

The initial direct browser capture reproduced two favicon 404 console errors; the game now provides its own inline SVG favicon. The handoff's historical console-12 / policy-6 counts did not include their original per-event records, so their individual historical causes cannot be reconstructed from the provided artifacts. This round records fresh HTTP, console, page-error and CSP events without suppressing them. Subjective audio listening and independent device/quality scoring remain external review work.
