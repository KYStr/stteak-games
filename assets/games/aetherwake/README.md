# Aetherwake reusable asset kit 1.0

Source of truth: `games/aetherwake/src/models.js`, `audio.js`, and
`games/aetherwake/scripts/export-assets.mjs`. The source snapshots and original
WAVs under this directory are reproducible delivery sources, refreshed by export.

Rebuild from the repository root with:

```sh
node games/aetherwake/scripts/export-assets.mjs
```

The game pins Three.js 0.180.0. No network download, image model or Blender install
is required for reconstruction. Outputs are GLB 2.0 files, mono PCM WAVs, SVG UI
icons, independent collision descriptions and a manifest of measured hashes.

All models use metres, +Y up and +Z forward. Ground actors have their origin at
the base centre. Islands have their playable top at y=0 and visual volume below.
The authored island radii are 38/34/34/41/34/38 metres, matching the six world
islands; the runtime generator accepts a radius. Collision uses the requested radius and is never generated by probing
render triangles. Observatory and relic colliders are simplified interaction
volumes, separate from their meshes.

The pilot's bones are root → hips → torso → head/leftArm/rightArm, and hips →
leftLeg/rightLeg. All parts are skinned with explicit skin indices and weights.
`idle`, `run`, `jump`, `glide`, `land` use quaternion tracks. Idle/run/glide loop;
jump/land clamp once. No clip moves the root. Reuse the named bones and bind pose
when retargeting; skeleton changes require a major kit version.

Materials use roughness/metalness PBR, flat basalt normals and generated UVs.
No bitmap textures are needed. The colour palette is exported as `PALETTE`.
Transparent wind volumes are auxiliary effects with no collision. Each exposes
`userData.update(dt)` for local deterministic animation; they use instancing.
`createWind(type,{radius,height,length})` adjusts distribution without enlarging
individual arrows. Updrafts include three animated spiral arcs; horizontal winds
have twin volumetric streamlines. Do not scale the entire wind group to fit a field.

Each island has a distinct landmark retained in both LODs: sail shelter, reed gate,
broken bridge portals, lightning frame, library columns, and the dawn dome.
Solid uprights and their footprints stay beyond 1.04 times the playable radius;
the circular landing area has no newly introduced solid obstruction. Their local
positions and dimensions are retained with the separate collider data. Basalt
outcroppings below the edge visually anchor the peripheral architecture.

Runtime budgets: six islands have two LODs each; only one LOD per island is drawn.
Static island/observatory/fragment parts are merged by material. Repeated plants
and wind arrows are InstancedMesh. See each manifest's measured draw calls and
triangle counts; actual scene draw calls include lighting/shadows and are tested
by the owning game. Materials are shared; geometry disposal is exposed by
`disposeModel`. Shadows can be disabled independently by the game's quality mode.

Audio opens only from a user gesture via `unlock()`. `setPaused(true)` suspends
the AudioContext. There are at most 20 event/melody voices plus one continuous
wind source. Events have cooldowns; music/SFX levels are independent. Dispose
stops voices and closes the context. Original WAVs are mono, 22050 Hz, PCM16;
the environmental loop is 12.8 seconds and wraps tails at the exact loop boundary.
The live wind buffer uses the AudioContext's sample rate. Peak values and sample
counts are recorded per asset. Six rendered event WAVs are loaded locally after
unlock; synthesis remains an offline-safe fallback.

`manifest.json` records sources, real SHA-256 hashes, byte sizes, rights and
dimensions. Runtime copies live only under `public/games/aetherwake/assets/`;
no evidence directory is an execution dependency.
