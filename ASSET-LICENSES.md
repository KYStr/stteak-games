# Asset terms and provenance

This source distribution preserves the existing per-asset records. It does not claim independent rights clearance or silently convert every model, sound or image to MIT/public domain.

| Game | Retained origin/permission record |
|---|---|
| Aetherwake | `assets/games/aetherwake/manifest.json`: project-authored procedural geometry/audio, ownership subject to the project owner's applicable terms |
| Dust Redemption | `assets/games/dust-redemption/manifest.json`: original project assets reusable/modifyable with the project; `audio/manifest.json`: existing **CC0-1.0** synthesized-audio declaration |
| Hollow Crown | `assets/games/hollow-crown/manifest.json` and `audio-manifest.json`: original procedural geometry, texture recipes and sound synthesis; Three separately MIT |
| Moss & Moon | `assets/games/moss-and-moon/manifest.json` and `audio-manifest.json`: original project geometry and sound composition; no public-domain claim |
| Neon Drift | `assets/games/neon-drift/manifest.json` and `audio-manifest.json`: original project geometry/materials and synthesized audio |
| Orbit / Fall | `assets/games/orbit-fall/manifest.json`: original procedural assets plus separately MIT-licensed Three helper entries |
| Signal Zero | `assets/games/signal-zero/manifest.json`: project-authored models/audio, reuse within and derivative from the project as stated in the retained records |
| Tidebound | `assets/games/tidebound/manifest.json` and `audio-manifest.json`: original project geometry, materials and synthesized audio; retained project-specific terms |

Original code used to generate these assets is covered by the first-party MIT grant, except third-party code explicitly identified in the notices. Existing media-specific grants remain as recorded; where a record does not give a specific broad media license, do not infer a new unrestricted/public-domain grant from the code license alone.

The public launcher does not use the platform's generated marketing artwork. No new image generation or 2D replacement of actual game geometry is part of this source release.
