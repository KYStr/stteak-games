# Asset provenance and reconstruction boundary

All retained historical asset records and recipes are exact public bytes from KYStr/stteak-games at `833c5214d33c0f89776c81d86df118d714760c6e`. Per-file Git blob and SHA-256 are in SOURCE-MAP.json. The delivered runtime is independently pinned to the served32 capsule at `6268b406efe9df3f11e1df7d99ad19e0057d91b9`. Equal source bytes do not establish that a recipe regenerated every delivered output.

The records describe project-authored procedural geometry, rig/animation and oscillator audio. The editable runtime models.js/audio.js and the retained procedural-models.js/audio source allow inspection; all exported GLBs and collider data remain exact runtime bytes. The historical asset manifest is retained unchanged, including historical measurements and creator labels. Those labels identify original records, not the recovery assembler. It is not a new validation result.

`export-assets.mjs` imports the pinned Three package and source modules, exports GLBs, reloads them, and writes runtime assets, source snapshots, manifest and validation JSON. It has NOT been executed in this recovery. `export-audio.mjs` invokes Playwright Chromium/OfflineAudioContext, optionally an explicitly supplied trusted executable, writes reference WAVs and changes the historical manifest. It has NOT been executed. Historical audio-brief prose mentions Edge, while this fixed public recipe defaults to Chromium: the recipe is authoritative for its actual browser selection. No new browser installation, native run, PCM reproduction or listening assessment is claimed.

Fifteen historical WAV references and five test paths are listed in CANONICAL-REFERENCE-INDEX.json but their bytes are not included here. References in historical briefs to verification scripts, render previews, screenshots, validation files or procedural-models-candidate.js likewise do not mean those files are delivered. Missing files must not be silently synthesized. Normal runtime audio is oscillator synthesis, not WAV downloads, as stated in the retained source records.

Asset-specific permission records remain unchanged; code MIT does not turn all media into public domain. LICENSE-SCOPE, ASSET-LICENSES and THIRD_PARTY_NOTICES are repository-wide historical notices: references to other games are contextual, not bundled content. Preserve the runtime Three license. Rights clearance and actual asset regeneration are not newly certified.
